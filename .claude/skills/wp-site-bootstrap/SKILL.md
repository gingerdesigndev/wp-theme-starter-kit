# 開站六步

**正文在 `docs/00-開站六步.md`，動手前完整讀一遍。**

這支 skill 只負責觸發；兩條起點分支（既有站搬遷 / 全新建站）、六步表、
SSH 與 Application Password 的實際指令都在那份文件裡，不要在這裡重複——
重複兩份一定會漂移。

## 開始前先確認

- 先判斷是「遷移既有站」還是「全新建站」——第 1、2 步的做法不同，見 `docs/00` 開頭的分支說明
- 遷移既有站時，別急著停用舊的頁面建構器——有硬依賴順序，見 `docs/00`
