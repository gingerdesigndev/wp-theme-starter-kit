# 開工流程

從上次收工的 HANDOFF.md 把 context 接回來。

## 第一步：讀檔

在**專案根目錄**（這個站的主題根目錄，不是使用者個人電腦上的全域設定路徑）依序檢查：

1. `HANDOFF.md` — 必讀
2. `MEMORY.md` — 如有則讀

如果 `HANDOFF.md` 不存在，跟使用者說：

> 找不到 HANDOFF.md（路徑：`./HANDOFF.md`）。是不是換了資料夾？還是上次沒收工存檔？

然後停下等指示，**不要自己亂猜要做什麼**。

## 第二步：用最多 3 句話確認

讀完後用這個格式回覆：

```
上次做到：<HANDOFF 的「這次做了什麼」摘要，1 句話>
還沒做完：<TODO 摘要，1 句話>
下一步：<HANDOFF 的「下次怎麼接」摘要，1 句話>

對嗎？要直接從這裡接？
```

如果有 MEMORY.md，順手提一句「另外讀到 MEMORY 有 N 條長期慣例，會一併套用。」

## 第三步：等指令

**不要主動開始動工。** 等使用者說「對，繼續」或給新指令再開始。

如果使用者說「對」或「繼續」之類的同意詞，就照 HANDOFF 的「下次怎麼接」開始執行。
