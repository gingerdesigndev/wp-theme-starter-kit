# 部署 SOP

**正文在 `docs/04-部署SOP.md`，動手前完整讀一遍。**

這支 skill 只負責觸發；`.deploy.env` 設定、`./deploy.sh` 的連線紀律與五層驗證
都在那份文件裡，不要在這裡重複——重複兩份一定會漂移。

## 開始前先確認

- SSH 金鑰已經裝上主機（沒有的話先做 wp-site-bootstrap 的第 4 步）
- 部署前先自己開真實瀏覽器看一眼版面，別只信 headless 截圖
